# Codex working instructions

Read [PROJECT.md](PROJECT.md) at the start of every task. It is the shared,
tool-neutral source of truth and overrides this file if there is a conflict.

Also read the documents relevant to the task:

- [README.md](README.md) for setup and existing commands.
- [ARCHITECTURE.md](ARCHITECTURE.md) for the current code structure.
- [CHANGELOG.md](CHANGELOG.md) for project history.
- [docs/IMAGE_ASSET_REGISTER.md](docs/IMAGE_ASSET_REGISTER.md) for image work.

Codex-specific rules:

- Explain decisions, questions and summaries to the user in Hebrew.
- Keep code and code comments in English.
- Change nothing outside the approved task scope.
- Never deploy without explicit approval.
- For image candidates, do not replace or overwrite an existing asset until the
  user explicitly approves that candidate number.
- Update the shared documentation only after the corresponding work was
  actually performed and verified.
