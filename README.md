# NOGA Fine Jewelry — אתר הדגמה

אתר תדמית לתיק עבודות, עבור מותג תכשיטים בדיוני מתל אביב. **דמו בלבד** — אין
תשלומים, הזמנות או מלאי אמיתיים — אבל ההתנהגות והעיצוב נבנו ברמת ייצור.

עברית מלאה, RTL, מחירים בשקלים. הנחיות המותג, העיצוב, ה־3D והנגישות מרוכזות
ב־[PROJECT.md](PROJECT.md), שהוא מקור האמת המשותף ל־Codex ול־Claude Code.
מסמך זה מתאר איך מריצים ואיפה הדברים נמצאים;
[ARCHITECTURE.md](ARCHITECTURE.md) מתאר את מבנה הקוד בפירוט.

## הרצה

```bash
npm install
```

```bash
npm run dev
```

| פקודה | מה היא עושה |
| --- | --- |
| `npm run dev` | שרת פיתוח (Vite) על `localhost:5173` |
| `npm run build` | `tsc --noEmit` ואחריו build לפרודקשן |
| `npm run preview` | הצגת ה־build מתוך `dist/` |
| `npm run typecheck` | בדיקת טיפוסים בלבד |
| `npm run verify` | בדיקת עשן בדפדפן אמיתי (Playwright) — `scripts/verify-site.mjs` |

## סטאק

React 19 · Vite 8 · TypeScript 7 · Tailwind v4 · react-three-fiber · drei ·
motion · lenis · zustand · react-router 7.

הכול צד־לקוח. אין backend, אין API keys, אין קריאות רשת חיצוניות. העגלה נשמרת
ב־`localStorage`, והצ׳קאאוט מעוצב אך לא פונקציונלי.

## עוזר בחירה (Shopping Assistant)

ווידג'ט הנחיה שמצמצם מ־16 הפריטים בקטלוג לפי ארבע שאלות: למי התכשיט, טווח
מחירים, קטגוריה ומתכת. מציג עד שלוש המלצות, ומחבר לפעולות האמיתיות של האתר —
מעבר לעמוד מוצר, הוספה לעגלה, מדריך מידות ווואטסאפ.

**שלב 1: דטרמיניסטי לחלוטין.** אין LLM, אין קריאת רשת, אין מפתח API. כל תשובה
מחושבת מ־`src/data/products.ts` בזמן ריצה, ולכן העוזר לא יכול להמציא פריט או
מחיר שלא קיים בקטלוג. הוא גם לא מצהיר על מלאי, זמני אספקה, מבצעים או דמי
משלוח — נתונים שלא קיימים בפרויקט. שאלה על אלה מקבלת תשובה כנה והפניה לוואטסאפ.

הארכיטקטורה מוכנה לשלב 2 (מוח מבוסס LLM) דרך ממשק `AgentBrain` — פרטים
ב־[PROJECT.md](PROJECT.md). **שלב 2 אינו מאושר**: הוא מחייב serverless function
שתחזיק מפתח API, וזה שובר את האילוץ "client-side only, no backend".

## פריסה

היעד הוא Vercel. `vercel.json` מגדיר rewrite של כל הנתיבים ל־`index.html` (SPA).
לייצור אמיתי נדרש SSR או pre-rendering — עמודי מוצר שנרנדרים בצד הלקוח
מאונדקסים גרוע.

## נגישות

ת"י 5568 / WCAG 2.0 AA: ניגודיות 4.5:1 לטקסט, ניווט מלא במקלדת, פוקוס נראה,
טקסט אלטרנטיבי, כיבוד `prefers-reduced-motion` (כולל כיבוי מלא של ה־3D), והצהרת
נגישות. זהב הוא צבע דקורטיבי בלבד ולא משמש לטקסט.
